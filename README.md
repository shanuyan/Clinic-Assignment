# Sunrise Dental Clinic Management System

## Overview
A professional, distributed Java-based solution for modernizing dental clinic operations. This system handles patient registration, appointment scheduling, automated billing, and performance analytics.

## Key Features
- **Automatic Database Setup**: Zero-config initialization.
- **3-Tier Architecture**: Scalable and maintainable codebase.
- **Design Patterns**: Implementation of Singleton, Facade, DAO, and Service patterns.
- **Modern UI/UX**: Professional dashboard with Dark Mode support.
- **Distributed API**: JSON endpoints for third-party integration.
- **Advanced Billing**: Automated invoicing with QR Code generation and Print support.

## Technologies Used
- **Backend**: Java EE, Servlets, JDBC
- **Frontend**: JSP, Bootstrap 5, Chart.js
- **Database**: MySQL
- **Tooling**: Ant/NetBeans, Git

## Setup Instructions
1. Clone the repository.
2. Configure your MySQL credentials in `com.clinic.util.DBConnection`.
3. Deploy the project to a Tomcat server.
4. Access via `http://localhost:8080/Sunrise_Dental_Clinic`.
